# Webhooks

**There are none.** Cairn has no webhook endpoint, no subscription model and no callback registry.

This page exists because the API section would otherwise imply one by omission. Inventing an
endpoint in documentation is the same failure as inventing a metric on a page: a reader plans
against it, and it is not there.

## What to do instead

Poll the lookup endpoint before you act. It is free, needs no auth, and a verdict is arithmetic over
the record rather than an expensive computation.

```
curl -s "$CAIRN/v1/lookup/0x..." | jq -e '.standing == "grounded"'
```

## What the agent does internally

Cairn's own loop does have a handoff mechanism, but it is internal rather than a public API. The
`forward` field on every journal event carries what the next session must pick up: counterparties
due for re-check, claims awaiting corroboration, claimants whose weight is still provisional. See
[How Cairn promotes and decays](/docs/memory/promotion).

If a push mechanism is built, it will be documented here rather than announced here first.
